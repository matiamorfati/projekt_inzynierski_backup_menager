Create Backup

Run a manual backup and decide whether it should be uploaded to Google Drive.

Manual backup

Provide source paths, select where the backup should land and override Google Drive upload only for this run.

Separate multiple paths with ; or put each path in a new line. Use Browse to open your file explorer and pick folders or files.

Decide whether this backup should be uploaded to Google Drive, saved locally, or both.

How it works

  • Backups are created by BackupManager.create_backup() and stored in SQLite via DatabaseManager.
  • This form calls /api/backups/run/, which uses core_service.run_backup_from_sources().
  • Backup destination options:
    • Google Drive – upload only.
    • Local only – store on disk, skip Drive.
    • Both – keep a local copy and upload.
  • You can check the result in the History tab and in email notifications.

Suggested manual backup options

  • Exclude patterns (e.g., node_modules, temp files).
  • Compression level toggle (fast vs. maximum).
  • Post-backup verification (hash comparison).
  • Automatic cleanup of old backups per retention policy.

A web-based backup management system developed as an engineering (BSc) project, focused on automating and simplifying the process of creating, managing, and restoring data backups.

The application allows users to configure and execute backup operations through a clean web interface. It provides access to backup history, basic restore functionality, and system status monitoring.

This project was developed as part of an engineering thesis and served as a practical introduction to building a full-stack application from scratch.
It required designing system architecture, integrating multiple layers (backend, web framework, frontend), and solving real-world problems related to data handling and user interaction.

The project was developed in a team environment, involving:

* division of responsibilities across backend, frontend, and system design,
* collaborative problem-solving and debugging,
* version control and coordination using Git.

Working in a team setting significantly improved communication skills, code organization, and the ability to integrate independently developed components into a cohesive system.

Tech Stack:

* Backend: Python
* Web Framework: Django
* Frontend: HTML, CSS, JavaScript
* Version Control: Git

Key Features

* Backup configuration and execution
* Backup history tracking
* Basic restore functionality
* Web-based user interface
* Communication between frontend and backend via HTTP requests

Skills needed to complete the project:

* Designing and structuring a full-stack application
* Working with Django and server-side logic
* Handling client–server communication
* Building modular and maintainable frontend code
* Collaborating effectively in a development team

This project reflects both technical skills and the ability to work in a team to deliver a complete, functional system.
